## 🌟 About the Project

Skilline is a modern marketing landing page built for educational platforms. 

This project is a **nicely updated revamping of the UI** originally inspired by this [Figma Community Design](https://www.figma.com/community/file/1029023791566203786/online-learning-landing-page?q_id=873fad7d-307e-427b-b83e-38aa92a802be). We've taken the original concept and evolved it into a fully responsive, polished, and interactive web experience.

### ✨ Highlights
- **Fully Responsive Layout**: Adapts gracefully to mobile, tablet, and desktop screens.
- **Revamped UI/UX**: Enhanced colors, typography, and spacing for a premium, modern feel.
- **Interactive & Dynamic**: Includes smooth animations, loaders, and interactive components.
- **Modern Architecture**: Built from the ground up using React 18, TypeScript, Vite, and Tailwind CSS v4.

## 💻 Getting Started

To run this project locally, follow these steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start the development server**:
   ```bash
   npm run dev
   ```
   *The server will start at `http://localhost:5173` by default.*

### Scripts

| Script              | Description                             |
| ------------------- | --------------------------------------- |
| `npm run dev`       | Start the Vite dev server               |
| `npm run build`     | Typecheck, then build to `dist/`        |
| `npm run preview`   | Serve the production build locally      |
| `npm run typecheck` | Run TypeScript with no emit             |

## 📂 Project Structure

```text
src/
  ├── components/       # Reusable UI components and page sections
  │   ├── sections/     # Modular sections of the landing page
  │   └── ui/           # Generic UI components
  ├── assets/           # Images, vectors, and shared visual assets
  ├── hooks/            # Custom React hooks (e.g. useInView)
  ├── styles/           # Global stylesheets (Tailwind entry points)
  ├── App.tsx           # Main application wrapper
  └── main.tsx          # React entry point
```
